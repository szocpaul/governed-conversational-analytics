    What data can I ask about?

    • Tickets — customer support tickets raised by merchants, with priority, category, timestamps, SLA outcomes, and satisfaction scores.
    • Merchants — the businesses the tickets belong to, described by sector, tier, and region.
    • Agents — the support agents handling tickets, described by tier, primary category, and shift region.

    You can ask about

    • Priority (P1–P4)
    • Category
    • Status (open or closed)
    • SLA compliance (first response and resolution)
    • CSAT score (customer satisfaction)
    • Resolution time
    • First response time
    • Reopen count
    • Assigned agent
    • Merchant
    • Merchant sector
    • Agent tier

    Read-only governed access via GraphJin. The model never executes arbitrary SQL. Latency is observational only.
